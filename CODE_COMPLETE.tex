\section{Project Overview}
% ===================================================================

This document contains the complete source code for the \textbf{Variational Quantum Eigensolver (VQE) Modal Analysis} project. The codebase implements a quantum-classical hybrid pipeline for computing natural frequencies and mode shapes of structural systems (beams and 2D Warren trusses).

\section{Conclusion}
% ===================================================================

This document contains every Python source file in the repository along with the LaTeX report template. The complete pipeline covers:

\begin{enumerate}
    \item \textbf{Beam FEA} --- Euler-Bernoulli elements, simply-supported BCs, analytical validation
    \item \textbf{1D Truss FEA} --- Axial bar elements, fixed-fixed BCs, analytical validation
    \item \textbf{2D Warren Truss FEA} --- Triangular mesh, pinned-roller BCs, proper geometry
    \item \textbf{Quantum Hamiltonian} --- $H = M^{-1/2} K M^{-1/2}$, Pauli decomposition, normalization
    \item \textbf{VQE Solver} --- Multi-start optimization, two-stage refinement, excited-state deflation
    \item \textbf{Visualization} --- Convergence curves, mode shapes, frequency comparisons, animations
    \item \textbf{Novel Studies} --- Ill-conditioning (tapered structures), damage detection (stiffness reduction)
    \item \textbf{Optimizer Comparison} --- COBYLA vs L-BFGS-B benchmarking
\end{enumerate}
